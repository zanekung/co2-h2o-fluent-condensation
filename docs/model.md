# 模型、几何与工况

## 几何和网格

计算域是二维轴对称喷管内的半截面：x=0–0.25 m，r=0–R(x)。收缩段 0.1 m、扩张段 0.15 m；入口、喉部、出口半径分别为 0.01995、0.00645、0.00775 m。无额外入口直段、喉部圆角或下游分离器。

收缩壁面令 q=x/0.1、Rt=0.00645、Rin=0.01995：

```text
f = (1-q²)² / (1+q²/3)³
R = Rt / sqrt(1 - (1-(Rt/Rin)²)*f)
```

扩张段是直线 `R=Rt+(0.00775-Rt)*(x-0.1)/0.15`。曲线来源记录保留在 [mesh_metadata.json](../mesh/mesh_metadata.json)；这里给出的具体公式和尺寸是本案例的完整几何定义。

结构化网格为 400×75 个四边形单元，共 30476 节点、60475 面。轴向 0–0.07/0.07–0.13/0.13–0.25 m 分别 70/180/150 段；径向坐标为 `R*tanh(3j/75)/tanh(3)`，向壁面聚集。喉部首层厚度约 2.663 μm。网格由代码生成，未使用 CAD 图像反推，也没有网格独立性证明。

## 液相变量和 UDF

UDS0 = L，单位 kg 液态水/kg 气体；UDS1 = N/10¹⁵，其中 N 是每 kg 气体的液滴个数。体积数密度为 ρgN。诊断液相质量分数为 β=max(L,0)/(1+max(L,0))。保存的负 UDS 原值没有被后处理覆盖。

26 个 UDM 保存过饱和度、成核/增长、半径、相变源、β、限幅与风险等字段，详见 [字段字典](field_dictionary.csv)。源码分工：

- [co2_h2o_condensation.c](../udf/co2_h2o_condensation.c)：Fluent 挂接和源项。
- [condensation_core.c](../udf/condensation_core.c)、[condensation_core.h](../udf/condensation_core.h)：凝结核心计算。
- [quasi1d_initialization.c](../udf/quasi1d_initialization.c)：变比热准一维初场。

正 Γ 表示凝结；气相质量和水蒸气源为 −Γ，液体生成与 +Γ 对应，气相动量包含 −Γu。能量实现为：

```text
S_E = -Γ [h_l(T) + |u|²/2]
    =  Γ [L_v(T) - h_v(T) - |u|²/2]
```

ICCT 形式含 exp(Θ)/S，未标定修正系数取 1；液滴增长采用 Gyarmathy 形式与混合气热物性。UDS 扩散系数为 μt/0.9 + 10⁻¹² kg/(m·s)。局部存量每步限制为 10%，成核率数值上限为 10³⁵ m⁻³s⁻¹；有近空群清理、半径限幅及对应诊断。保护机制是否影响解，需要额外敏感性分析。

水蒸气/液水 Cp 分别为 1864/4181.3 J/(kg·K)，参考温度 298.15 K、参考潜热 2441700 J/kg。CO₂ 的分段比热及部分输运参数按原建模中观察到的 Fluent 物性设置保存，源码保留出处；不是本案例原创实验物性。未重分发物性数据库整体。

## 模型边界

没有独立液滴动量/能量方程，已有液滴的加速和储能未完整耦合；没有显式 CO₂ 扩散阻力、独立液滴温度、冰、干冰、水合物、聚并/破碎、沉积或下游分离。低温物性外推需审查。出口凝结比例不能自动解释为设备分离效率。

初场、求解器残差和全程完成证明不了这些简化的物理准确性。[验证说明](validation.md)列出已知结果与待验证问题，[参考文献](references.md)区分方法来源和真正的验证基准。
